Contexto del Proyecto

Contexto: El screening AutoML identificó el mejor candidato como referencia (TabPFN v2: F1=0.8496, AUC=0.9644). La Fase 4 EDA confirmó las features más relevantes.

Objetivo Fase 5: Entrenamiento manual y controlado de 21 algoritmos sobre 33.621 expedientes. Métrica principal: F1 (clase abandono). Selección del top-3 para Fase 6 (interpretabilidad + fairness).
