🎯 ¿Qué encontrarás en este manual?

Esta guía explica paso a paso cómo descargar el código del proyecto desde GitHub y poner en marcha el orquestador maestro sin necesidad de conocimientos previos de informática. Está pensada para el tribunal del TFM, profesorado, compañeras o compañeros de clase, y cualquier persona del ámbito universitario que desee reproducir el pipeline.

💡 Tres formas de revisar el proyecto:
  • Vista rápida (sin descargar nada): visitar la app desplegada en tfm-abandono-dinamico.streamlit.app
  • Vista intermedia (sin descargar nada): navegar la documentación web en mortemj.github.io/AU_UJI_v2
  • Vista detallada (requiere descarga): seguir este manual y ejecutar el orquestador en local.

📋 Resumen de pasos

Para reproducir el proyecto entero hay que hacer estas 6 cosas:

  1. Descargar el código desde GitHub ~5 min
  2. Instalar Anaconda (Python + Jupyter) ~10 min
  3. Instalar las librerías necesarias ~5 min
  4. Conseguir los datos: usar los de prueba o los propios ~3 min
  5. Validar que los Excel son correctos ~2 min
  6. Lanzar el orquestador maestro ~10 min

⏱️ Tiempo total estimado: ~35 min (la primera vez). Las siguientes ejecuciones son inmediatas.

1️⃣ Descargar el código desde GitHub

A

Opción fácil — Descargar como ZIP (recomendada)

  1. Abre el navegador y entra en https://github.com/mortemj/AU_UJI_v2.
  2. En la parte superior derecha verás un botón verde grande que pone <> Code. Púlsalo.
  3. Se abrirá un menú desplegable. Al final del menú, pulsa 📥 Download ZIP.
  4. Se descargará un fichero AU_UJI_v2-master.zip a tu carpeta de Descargas.
  5. Haz clic derecho → Extraer todo… sobre el ZIP, y elige una carpeta sencilla, por ejemplo C:\AU_UJI_v2 (Windows) o ~/AU_UJI_v2 (Mac/Linux).
B

Opción avanzada — Clonar con Git (solo si ya conoces Git)

Abre la consola y ejecuta:

git clone https://github.com/mortemj/AU_UJI_v2.git
📥 Ir al repositorio en GitHub

2️⃣ Instalar Anaconda (Python + Jupyter)

Anaconda es un programa gratuito que instala todo lo necesario: Python, Jupyter y un gestor de librerías. Si ya tienes Anaconda instalado, salta al paso 3.

1

Descargar e instalar

  1. Entra en www.anaconda.com/download.
  2. La página detecta tu sistema y ofrece el instalador correcto. Pulsa Descargar.
  3. Doble clic sobre el archivo descargado.
  4. Acepta todas las opciones por defecto (Next → I Agree → Just Me → Next → Install).
✅ Al terminar debe aparecer Anaconda Navigator en el menú Inicio o Launchpad.
⬇️ Descargar Anaconda

3️⃣ Instalar las librerías necesarias

1

Abrir Anaconda Prompt

  • Windows: menú Inicio → escribe Anaconda Prompt → Enter.
  • Mac/Linux: abre la Terminal (conda ya está en el PATH).
2

Crear el entorno y las librerías

Ejecuta estos comandos uno a uno (cambia C:\AU_UJI_v2 por la carpeta donde extrajiste el proyecto):

cd C:\AU_UJI_v2
conda create -n tfm_abandono python=3.11 -y
conda activate tfm_abandono
pip install -r notebooks/requirements.txt
⚠️ Si aparece un error sobre versiones de paquetes: probablemente sea por un paquete pesado (TensorFlow, H2O). Para una revisión rápida no son imprescindibles. Avisa por email a la autora si necesitas el entorno completo.

4️⃣ Conseguir los datos (elige una de las dos rutas)

El pipeline necesita 2 ficheros Excel en data/00_raw/. Tienes dos rutas posibles según los datos que tengas disponibles. Lee las dos y elige la que aplique a tu caso:

🅰️ Ruta A — Usar los datos DEMO (50 alumnos ficticios) RECOMENDADA

Esta es la opción por defecto: el repositorio incluye un Excel reducido con 50 alumnos ficticios para que puedas probar el pipeline sin acceso a los datos reales. El proceso es automático:

  1. En Jupyter, abrir notebooks/fase0_configuracion/f0_setup_demo.ipynb.
  2. Pulsar Cell → Run All.
  3. El notebook descomprimirá automáticamente data/demo/demo_excel.zip a data/00_raw/ con los nombres correctos.
🛡️ Protección automática: el notebook detecta si en data/00_raw/ ya hay datos reales (más de 1.000 filas). Si los detecta, NO los toca: solo instala los DEMO si no hay riesgo.

Nota: los 50 alumnos están seleccionados de forma equilibrada (~25 abandonan, ~25 finalizan). Las métricas finales serán diferentes a las del informe del TFM porque el modelo entrena con poquísimos datos. El objetivo es verificar que el pipeline funciona, no reproducir resultados.

🅱️ Ruta B — Usar los Excel originales (datos reales)

Solo aplica si has recibido los Excel originales por canal seguro (María José vía Drive, o de la UJI directamente).

  1. Coloca los 2 ficheros recibidos en data/00_raw/.
  2. Verifica que se llaman exactamente:
    • datos_proyecto_sin_preinscrip.xlsx
    • preinscripcion_si.xlsx
  3. NO ejecutes f0_setup_demo.ipynb en este caso (está protegido y no haría nada, pero no es necesario abrirlo).
⚠️ Importante: los datos originales contienen información sensible y están protegidos por RGPD. No deben compartirse, copiarse a la nube ni enviarse por correo electrónico no cifrado.

5️⃣ Validar que los Excel son correctos

Antes de lanzar el orquestador, hay un notebook que valida la estructura de los Excel en 5 niveles (existencia, hojas, columnas, tipos de datos y cruces de IDs).

1

Abrir Jupyter

Opción A: con un solo doble clic, usa el arrancador automático del proyecto:

arrancar_proyecto.bat   (Windows)
./arrancar_proyecto.sh   (Mac/Linux)

Opción B: manualmente desde Anaconda Prompt:

jupyter notebook notebooks/fase0_configuracion
2

Ejecutar el notebook de validación

  1. Doble clic sobre f0_validar_excel.ipynb.
  2. Menú superior: Cell → Run All.
  3. Espera 2–3 minutos. Al final aparecerá un resumen con los 5 niveles.
✅ Resultado esperado: mensaje final "VALIDACIÓN CORRECTA — puedes continuar con F1".
❌ Si falla algún nivel bloqueante (N1–N3): se generará un informe HTML en docs/html/fase0/validacion_excel.html con el detalle del error.

6️⃣ Lanzar el orquestador maestro

💡 ¿Qué hace el orquestador maestro?
  • Antes de empezar, valida los Excel (los mismos 5 niveles del paso anterior).
  • Lanza el orquestador de cada fase (un notebook por fase).
  • Regenera todos los HTMLs del proyecto con los resultados nuevos.
  • NO reentrena los modelos pesados: carga los modelos .pkl ya entrenados.
1

Abrir el orquestador y ejecutar las primeras celdas

  1. En Jupyter, abre orquestador_maestro.ipynb (en la misma carpeta de F0).
  2. Menú superior: Cell → Run All.
  3. Las primeras celdas son rápidas (configuración, imports, validación pre-fase, estilos).
2

Pulsar el botón ▶️ Comenzar Fase 1

  1. Aparecerá un panel con el botón grande ▶️ Comenzar Fase 1.
  2. Tras cada fase aparecerán dos botones:
    • ▶️ Continuar siguiente fase
    • ⏸️ Parar aquí (útil si solo quieres ver una fase)
✅ Al terminar: abre docs/html/orquestador_resumen.html en cualquier navegador y verás el resumen completo del proyecto.
