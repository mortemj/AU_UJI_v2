El modelo elegido es LightGBM, ganador del proceso de selección dinámica documentado en f6_m00_preparacion. ¿Qué cambios mínimos en las características de un alumno harían que el modelo LightGBM predijera no-abandono? Generado con DiCE (Microsoft, 2020). Solo se modifican features accionables — variables sobre las que la universidad o el alumno pueden intervenir realmente. Las features fijas (edad, sexo, nota de selectividad...) se mantienen constantes.
