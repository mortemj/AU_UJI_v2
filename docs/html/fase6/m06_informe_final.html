1. Modelo Recomendado

Un modelo de predicción es un programa que aprende de datos históricos y luego es capaz de predecir si un nuevo alumno tiene riesgo de abandonar. En este trabajo hemos probado 21 modelos diferentes y comparado cuál detecta mejor los abandonos reales. El ganador es LightGBM, justificado por test estadístico Wilcoxon. combina las predicciones de tres modelos distintos (como un comité de expertos que vota) para llegar a una decisión más acertada. Las métricas clave son el AUC — qué tan bien separa abandonos de no abandonos (1.0 = perfecto, 0.5 = azar) — y el F1, que equilibra cuántos abandonos detecta con cuántas falsas alarmas genera.

5. Robustez y Calibración

Para comprobar si el modelo es fiable en condiciones reales, le sometemos a dos pruebas de estrés. Primero, añadimos ruido artificial a los datos — como si hubiera errores de medición o datos incompletos — y medimos cuánto se degrada la predicción. Segundo, eliminamos las variables más importantes para ver si el modelo puede seguir funcionando sin ellas. Un modelo robusto mantiene un buen rendimiento aunque los datos no sean perfectos.

Curva de robustez bajo ruido gaussiano

Degradación progresiva del AUC y F1 al añadir ruido a las variables numéricas. Zona verde = degradación aceptable (<2%). El modelo mantiene AUC > 0.88 con ruido del 30% — robusto para datos administrativos reales.

6. Limitaciones

  • Sesgo temporal: El modelo se entrena con datos 2010-2020. Cambios estructurales en el perfil del alumnado pueden degradar el rendimiento en cohortes futuras.
  • Equidad en vías de acceso minoritarias: Las métricas de fairness para grupos con pocas observaciones son estadísticamente inestables.
  • Definición de abandono: Alumnos en pausa temporal pueden clasificarse incorrectamente.
  • Variables no capturadas: Motivación, situación familiar o salud mental podrían mejorar la detección de falsos negativos.

7. Recomendaciones Institucionales

  1. Desplegar el modelo ganador como modelo de producción por su equilibrio entre rendimiento, velocidad e interpretabilidad.
  2. Aplicar calibración isotónica antes de usar probabilidades para priorizar intervenciones (mejora Brier de 0.0702 a 0.0702).
  3. Aplicar umbral óptimo 0.44 en lugar de 0.50 — mejora F1 de 0.8334 a 0.8344 (+0.0010). Si el objetivo es no dejar pasar ningún caso, bajar a 0.35-0.40.
  4. Intervención prioritaria en primer año para alumnos sin beca y con menos de 30 créditos superados.
  5. Intervención accionable con DiCE: las features con menor coste de contrafactual (créditos repetidos, años con beca, años trabajando) son las palancas de intervención más eficientes para reducir el abandono.
  6. Monitorizar equidad en vías de acceso minoritarias a medida que se acumulen más datos.
