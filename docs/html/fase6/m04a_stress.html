Fase 6 — M04a · Stress Testing: Robustez del Modelo

🏆 Selección del modelo: justificación estadística

El modelo elegido es LightGBM, ganador del proceso de selección dinámica documentado en f6_m00_preparacion. La comparación con los otros modelos del top mediante test de Wilcoxon pareado (5-fold CV, n_train=26,896, α=0.05) confirma que no existen diferencias estadísticamente significativas entre ellos:

Al no existir diferencia significativa en F1, se aplica el criterio oficial de desempate por recall sobre test (tolerancia 0,001), justificado por el coste asimétrico de los falsos negativos. Recall LightGBM = 0,8048 vs XGBoost = 0,8007 (∆ = 0,0041 → 8 personas estudiantes adicionales correctamente identificadas como en riesgo).

Evaluación de la robustez del modelo LightGBM ante perturbaciones controladas. Se simulan tres escenarios adversos: ruido gaussiano en las features numéricas, presencia de valores extremos y ausencia de las features más importantes. Un modelo robusto mantiene su rendimiento incluso con datos de baja calidad.

AUC y F1 bajo features ausentes

Degradación al eliminar progresivamente las features más importantes (imputadas con la mediana). Muestra cuánto depende el modelo de cada feature.

🏆 Degradación relativa (% pérdida vs baseline)

% de pérdida de AUC y F1 respecto al baseline. La línea ámbar marca el umbral del 5% — degradaciones por debajo indican un modelo robusto apto para producción.

Interpretación: Una caída de AUC inferior a 0.02 bajo ruido moderado (10-20% std) indica un modelo robusto. Caídas superiores a 0.05 sugieren sensibilidad excesiva que debería abordarse antes del despliegue en producción.
