🏆 Selección del modelo: justificación estadística

El modelo elegido es LightGBM, ganador del proceso de selección dinámica documentado en f6_m00_preparacion. La comparación con los otros modelos del top mediante test de Wilcoxon pareado (5-fold CV, n_train=26,896, α=0.05) confirma que no existen diferencias estadísticamente significativas entre ellos:

Al no existir diferencia significativa, se aplica criterio de estabilidad en validación cruzada. AUC std LightGBM = 0.0013 vs XGBoost = 0.0017 (variabilidad 21% menor en LightGBM).

Un modelo bien calibrado es aquel cuyas probabilidades predichas reflejan fielmente la frecuencia real de abandono. Si el modelo LightGBM predice 0.7 de probabilidad de abandono para un grupo de alumnos, idealmente el 70% de ellos debería abandonar. El Brier Score mide el error cuadrático medio entre probabilidades predichas y reales (0 = perfecto, 1 = pésimo).

🏆 Umbral óptimo de decisión

El umbral que maximiza F1 es 0.44, no el estándar 0.50. Con una prevalencia de abandono del 29%, bajar el umbral aumenta el recall (detecta más casos reales) a costa de más falsos positivos. Mejora de F1: +0.0010 (0.1%).

Distribución de probabilidades por clase real

Separación entre alumnos que abandonan (rojo) y los que no (azul). Una buena separación indica alta capacidad discriminativa del modelo.

Conclusión: El mejor método de calibración es Original con Brier Score = 0.0702. La calibración es relevante cuando las probabilidades se usan directamente para priorizar intervenciones (alumnos con prob > 0.6 reciben atención prioritaria), no solo para la clasificación binaria.
